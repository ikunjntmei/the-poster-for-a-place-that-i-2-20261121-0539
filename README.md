A travel poster for Velmara — a harbour town on a crescent bay where twice a day the tide climbs the sky: a slow waterfall of golden light rises from the harbour, up the white cliff face, and dissolves into the clouds. Its landmark is the Tide Stair, a white stone stairway strung with warm lanterns, climbing from the harbour steps to a small lighthouse on the cliff top.

`main.py` (Python 3.13, standard library only) paints the poster in code — dusk sky, low amber sun, teal bay, cliffs, the Tide Stair and its rising ribbon of light, boats, birds and mist — and sets the name VELMARA across the upper third in letterforms drawn from bitmap grids. It encodes the PNG by hand and writes it to `/output/entry.png`. The output is deterministic: every run produces the same file.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` — a 1024×1024 PNG travel poster for Velmara.
